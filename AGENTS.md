# Agent instructions

The instructions for this repository live in [`CLAUDE.md`](CLAUDE.md). Read it before making any change; it is the single source for the layout, commands and conventions.

- Conventions for specific parts of the code are in [`.claude/rules/`](.claude/rules). Each file lists the paths it applies to in its `paths:` frontmatter; read the ones that match the files you are changing.
- Procedures for recurring tasks are in [`.claude/skills/`](.claude/skills).

This file only points to those. Do not add instructions here; add them to `CLAUDE.md` or a rule so every agent reads the same thing.
